# 履历星图：业务与体验闭环审计

审计日期：2026-09-24。范围：前端路由与主要页面、API 封装、后端控制器/服务、迁移脚本、单元测试和本机服务探测。结论只对应当前工作区代码，不代表生产环境验收。

## 总体结论

**尚未全部闭环。** 主干功能已有可调用链路，但部分流程仍存在额度校验、失败恢复、数据隐私和部署验证的缺口。审计时前端 `127.0.0.1:5173` 返回 200，后端 `127.0.0.1:8080` 未启动，故无法声称已完成真实数据库、邮件、支付、AI 模型、浏览器语音设备的端到端验收。`npm test`、`npm run build`、`mvn test` 均通过；构建有大包体积警告。

状态说明：**代码闭环**＝入口、业务接口、持久化/结果和可见反馈在代码中均有链路；**部分闭环**＝可操作但存在已确认缺口；**未闭环**＝核心操作尚未提供；**待环境验收**＝代码已有路径但本次无法实际跑通外部依赖。

## 已确认的主要断点与修复优先级

1. **P0 导出与额度脱节**：`EditorView.vue` 先保存文件，再发起可能拒绝的导出记录接口；前后端需要设计“有额度才下载、下载失败如何退款/重试”的一致协议。验收：额度为零时所有格式均不能下载，服务不可用时不得误报成功；失败不应错误扣次。
2. **P0 所属账户信任边界（已修复三个入口，仍需全站验证）**：此前 `/resumes` 保存、`/ai/optimize`、`/export/record` 使用客户端传入的 `userId`；本次统一由服务端登录会话覆盖并加入控制器测试。进一步测试应使用两个真实账号、共享和非共享资源，覆盖模板收藏、社区及管理员接口。
3. **P1 首页/模板/社区离线体验**：`HomeView.vue` 原来在两个请求失败时显示模板数 0 和“持续增长”，本次调整为“—”；`TemplatesView.vue:89–100`、`CommunityView.vue:147–155` 的首轮并发加载失败尚无页面内重试按钮，继续完善错误页和重试。
4. **P1 隐私自助**：`SettingsView.vue:102–110` 数据副本导出和删除云端内容禁用；比赛展示时不要宣传为已上线。
5. **P1 部分练习的采纳链路**：证据句目前复制后手工进入编辑器；报告重练主要使用当次 `sessionStorage`，历史报告进入同题重练建议加固定入口。
6. **P2 移动端入口与性能**：职业实验室十项导航在窄屏横向滚动，首屏难以发现较后面的功能；构建输出的 `vendor`、`echarts` 包较大，需按比赛演示设备网络做首屏测试。

## AI 接口正文与推理泄漏修复（2026-09-24）

- 管理员模型测试曾把输出限制为 `max_tokens=16`。GLM-5.3 会先生成推理 token，第三方兼容接口因 `finish_reason=length` 返回 HTTP 200、`content=null` 时，没有用户可读正文；这是请求预算与解析问题，并非网络不通。
- 管理员测试和正式功能现统一发送 4096 输出 token；长度截断后只用 8192 再试一次（其他可重试错误最多两次尝试）。所有 AI 功能在同一服务端入口剔除 `<think>`、`<thinking>`、`<analysis>` 块及未闭合思考块，不从 `reasoning` 字段取正文。面试服务与前端消息入队再做防御过滤，避免思考内容进入问题、语音、报告与新记录。前端 AI 请求与管理员测试延长网络等待时间；后台新建模型配置默认 90000ms，旧配置需要手动调整并保存。
- 模拟第三方响应的单测覆盖 `content=null + reasoning + length`、长度重试、数组正文、已闭合及未闭合 `<think>`；后端 `mvn test`、前端 `npm test` 与 `npm run build` 通过。仍须使用有效第三方 API Key 和真实设备完成在线模型、延迟、费用、语音与报告验收；现有旧面试记录若含思考内容不会自动清洗。
